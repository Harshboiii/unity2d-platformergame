\# 2D Platformer Game



\## Project Overview

This project is a 2D platformer game developed using Unity. The player explores different levels, moves across platforms, avoids obstacles, and tries to reach the end of each level.



\## Features

\- 2D player movement and jumping.

\- Platform-based level design.

\- Two different game scenes.

\- Different backgrounds for each level.

\- Collision detection.

\- Level progression between scenes.



\## Technologies Used

\- \*\*Game Engine:\*\* Unity 6

\- \*\*Programming Language:\*\* C#

\- \*\*IDE:\*\* Visual Studio

\- \*\*Version Control:\*\* Git and GitHub

\## How to Run the Game

1\. Download or clone this repository.

2\. Open Unity Hub.

3\. Select \*\*Add Project from Disk\*\*.

4\. Choose the `platformer` project folder.

5\. Open the project using Unity 6.

6\. Open the first game scene.

7\. Press the Play button to start the game.



\## Controls

\- \*\*A / Left Arrow:\*\* Move Left

\- \*\*D / Right Arrow:\*\* Move Right

\- \*\*Spacebar:\*\* Jump
